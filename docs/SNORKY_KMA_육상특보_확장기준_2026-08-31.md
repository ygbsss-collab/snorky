# SNORKY KMA 육상특보 확장 기준

## 적용 범위

- 기존 해상특보 구역은 `points.warning_area_code`의 `S` 코드로 유지한다.
- 육상특보 구역은 `regions.land_warning_area_code`와 `points.land_warning_area_code`의 `L` 코드로 분리한다.
- 코드 형식은 각각 `^S[0-9]{7}$`, `^L[0-9]{7}$`를 따른다.
- 육상 Safety BLOCK 대상은 호우(`R`), 강풍(`W`), 태풍(`T`)의 주의보·경보이다.
- 기존 해상특보 및 Safety 점수 알고리즘은 변경하지 않는다.

## 포인트 매핑

- `regions.land_warning_area_code`를 육상특보 구역의 기준값으로 사용한다.
- 포인트 생성·지역 변경 시 DB trigger가 해당 region의 육상 코드를 `points.land_warning_area_code`로 자동 상속한다.
- region의 육상 코드가 변경되면 소속 포인트에 자동 전파한다.
- 포인트별 육상 코드를 수동 입력하는 방식은 사용하지 않는다.
- 기존 region의 공식 육상 `L` 코드 초기 매핑과 신규 region 생성 시 공식 코드 공급 경로는 별도 공식 구역 자료 연계가 필요하다. `[확인 필요]`

## 복수 특보 처리

- 포인트 평가 시 해상 `S` 코드와 육상 `L` 코드에 활성화된 특보를 합산한다.
- Safety 판정 데이터에는 활성 특보 전체를 유지한다.
- 해상·육상에서 같은 특보 종류와 등급이 중복되면 한 건으로 합친다.
- 대표 표시 우선순위는 다음과 같다.

1. 태풍경보
2. 태풍주의보
3. 풍랑경보
4. 풍랑주의보
5. 폭풍해일·지진해일
6. 호우경보
7. 호우주의보
8. 강풍경보
9. 강풍주의보

- 한 건이면 `입수 금지 · 태풍주의보` 형식으로 표시한다.
- 두 건 이상이면 `입수 금지 · 태풍주의보 외 1건` 형식으로 표시한다.
- 상세 내역에서는 중복 제거된 활성 특보 전체를 사용할 수 있다.
