Cache / Freshness / LKG 유효 Cache가 있으면 외부 API를 재호출하지 않는다. 동일 발표본 재호출을 금지한다. Lock으로 동일 작업 중복 실행을 막는다. Freshness Gate로 갱신 필요 여부를 판단한다. Usage Guard로 호출량을 제한한다. Raw Validation 통과 전 정상 Cache를 교체하지 않는다. 실패 시 LKG를 유지한다.
