Cache / Freshness / History Retention / LKG 유효 Cache가 있으면 외부 API를 재호출하지 않는다. Lock으로 동일 작업 중복 실행을 방지한다. Freshness Gate는 “최신 여부”를 판단하고, History retention은 Visibility 계산에 필요한 “과거 시계열 보존”을 담당한다. 두 개념을 혼동하지 않는다. Usage Guard로 호출량을 제한한다. Raw Validation 통과 전 정상 Cache를 교체하지 않는다. 실패 시 LKG를 유지한다.
