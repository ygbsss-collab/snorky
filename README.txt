# SNORK 프로토타입 v0.1

## 실행 방법
1. `index.html`을 더블클릭해서 브라우저로 엽니다.
2. 인터넷 연결이 되어 있으면 영덕 경정항 기준 실제 예보를 자동으로 불러옵니다.
3. 브라우저 보안 설정 때문에 로컬 fetch가 차단되면 VS Code의 Live Server로 `index.html`을 실행하세요.

## 현재 데이터
- Open-Meteo Marine API: 파고, 파주기
- Open-Meteo Weather API: 풍속, 강수
- API Key 없음 / 비상업적 무료 범위

## 현재 판정
- 85~100: 좋음
- 70~84: 보통
- 50~69: 주의
- 0~49: 나쁨
